# rjtd Research and Implementation Records

These records own CLI commands, Rust APIs, model/JSON contracts, rendering
approximations, regressions, and resource limits. Each starts with its current
scope and then preserves the detailed pre-separation mixed research record.
Historical capability, policy, and hypothesis statements are not current
format contracts. Original observations and counterexamples are retained,
along with fixed-commit links to the prior documents.

See the [format-facing drafts](../../../openjtd-spec/README.md) and the
[interpretation/rendering design](../../../docs/ARCHITECTURE.md). Shared
RFC 0001/0003 import history is unchanged. New shared claims require their own
evidence and review.
