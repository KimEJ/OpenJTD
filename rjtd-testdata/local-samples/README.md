# Local Ichitaro Samples

This directory is for personal Ichitaro files used during local manual checks.
Local corpora may be organized in subdirectories, for example
`ichitaro-source-y-probe/corpus/baseline-sweep/` and
`ichitaro-source-y-probe/corpus/page01-grid/`.
To inspect the current local inventory, use:

```sh
rg --files --no-ignore rjtd-testdata/local-samples
```
