# Local Ichitaro Samples

このディレクトリは、local manual checks に使う個人用 Ichitaro files のための場所である。
Local corpus は subdirectory に整理してよい。例:
`ichitaro-source-y-probe/corpus/baseline-sweep/` と
`ichitaro-source-y-probe/corpus/page01-grid/`。
現在の local inventory を確認するには次を使う。

```sh
rg --files --no-ignore rjtd-testdata/local-samples
```
