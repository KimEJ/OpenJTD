# openjtd-spec

JTD public specification と RFC 形式の reverse engineering records を管理する場所である。

`openjtd-spec` は OpenJTD の project-level specification space である。公開形式の知見を
単一実装に閉じ込めないため、`rjtd` Rust ツール群と同格に扱う。
