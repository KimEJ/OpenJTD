# RFC 0004: Implementation Model Export Record

Status: withdrawn as a format RFC; number reserved

English source: [0004-document-model-export.md](0004-document-model-export.md)

## 扱い

この番号は履歴のため保持する。以前の文書は Rust 実装の model、JSON schema、CLI、exporter
動作を記述していた。これらは実装の契約であり、JTD bytes を定義する観測ではない。
形式向け RFC 群から外し、番号は再利用しない。

当時の model/export 記録と範囲は下記の実装記録で管理する。この整理で共通 document model や
canonical JSON interchange 形式を定義するものではない。
