# RFC 0004: Implementation Model Export Record

Status: withdrawn as a format RFC; number reserved

Japanese translation: [0004-document-model-export.ja.md](0004-document-model-export.ja.md)

## Disposition

This number is retained for history. The former document described a Rust
implementation's model, JSON schema, CLI commands, and exporter behavior.
Those are implementation contracts, not observations defining JTD bytes.
It is withdrawn from the format-facing RFC set and is not renumbered.

The historical model/export record and its scope are maintained in the linked
implementation record below. No replacement shared document model or canonical
JSON interchange format is established by this withdrawal.
