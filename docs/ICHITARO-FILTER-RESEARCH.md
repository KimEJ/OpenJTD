# Historical Ichitaro Filter Research

The OpenOffice Ichitaro import filter is an optional historical reference for
specific interoperability questions. Current baseline research uses controlled
comparisons of documents authored in Ichitaro 2026; no external implementation
determines JTD semantics or becomes a required design precedent.

The local `.oxt` is under `third-party/ichitaro-filter/`. Artifact identity and
metadata observations are recorded in [RFC 0002](../openjtd-spec/rfc/0002-ichitaro-openoffice-filter.md).

## Current Implementation Boundary

Follow [CONTRIBUTING.md](../CONTRIBUTING.md) and the artifact's original terms.
The existing reference scope uses metadata, filter/type registration, package
inventory, visible strings, and independently observable application behavior.
Do not copy or reconstruct implementation logic from the DLL. Deeper analysis
requires a separately established permissible scope; this documentation cleanup
does not broaden it. Shared research-policy drafts and discussion directions
are not a substitute for recorded acceptance and artifact-specific conditions.

Keep hints, hypotheses, independently reproduced JTD observations, and output
approximations separate. A historical implementation is not the format authority.
